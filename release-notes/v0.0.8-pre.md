# GoRipper v0.0.8-pre

**Released:** 2026-03-26

## Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.0.8-pre
```

## Summary

Three analyst-quality-of-life features: binary diffing, a proper version command,
and `-o` file output across every subcommand.

## What's Included

| Feature | Description |
|---------|-------------|
| `goripper diff` | Compare two Go binaries — added/removed/modified functions, new strings, new behavior tags. `--json` and `-o` supported. |
| `goripper version` | Print version, Go toolchain, OS/arch, commit, and build date. |
| `-o / --output <file>` | Write output to a file on all subcommands instead of stdout. |
| `internal/diff` | New package — `Compare(a, b) *Result` + 5 unit tests. |
| `internal/version` | New package — ldflags-injected version vars with `String()` helper. |
