# GoRipper v0.0.8-pre — diff subcommand, version command, -o output flag

**Released:** 2026-03-26

## Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.0.8-pre
```

---

## Summary

Three analyst quality-of-life features: binary diffing, a proper version command,
and `-o` file output across every subcommand.

---

## What's new

### `goripper diff <binary1> <binary2>`

Compares two Go binaries and reports what changed:
- Functions added (in binary2, not binary1)
- Functions removed (in binary1, not binary2)
- Functions modified (same name, different size)
- New strings in binary2
- New behavior tags in binary2

Supports `--json`, `-o`, `--no-runtime`, and `--only-user` flags.

```bash
goripper diff v1.exe v2.exe --only-user
goripper diff v1.exe v2.exe --json | jq '.added'
```

### `goripper version`

Prints version, Go toolchain, OS/arch, commit, and build date:

```
v0.0.8-pre (go1.24.0 linux/amd64)
  commit: abc1234
  built:  2026-03-26
```

Version vars are injected at release time via `-ldflags -X`. Local dev builds show `v0.0.0-dev`.

### `-o / --output <file>`

Write output to a file instead of stdout on all subcommands. Path is printed to stderr.

```bash
goripper analyze malware.exe --json -o report.json
goripper diff v1.exe v2.exe -o diff.txt
```

## Tests

New packages with tests: `internal/diff` (5 tests), `internal/version` (3 tests).

| Test | Description |
|------|-------------|
| `TestCompare_AddedFunctions` | Functions in b but not a appear in `Added` |
| `TestCompare_RemovedFunctions` | Functions in a but not b appear in `Removed` |
| `TestCompare_ModifiedFunctions` | Same name, different size → `Modified` |
| `TestCompare_NewStrings` | Strings in b but not a appear in `NewStrings` |
| `TestCompare_NewBehaviors` | Tags in b but not a appear in `NewBehaviors` |
| `TestCompare_Identical` | Identical inputs produce empty diff |
| `TestString_NonEmpty` | `version.String()` returns non-empty string |
| `TestString_ContainsVersion` | Output contains the version var |
| `TestString_ContainsGo` | Output contains Go runtime version |
