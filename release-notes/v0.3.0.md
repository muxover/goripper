# GoRipper v0.3.0 — Section entropy, embedded assets, constant extraction, HTML report

**Release date:** 2026-05-15

### Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.3.0
```

Or download a prebuilt binary from the [releases page](https://github.com/muxover/goripper/releases/tag/v0.3.0).

---

## Summary

Five new analysis capabilities and a self-contained HTML report format. Section entropy reveals packed and encrypted regions at a glance. Embedded asset paths are detected via callgraph-guided string matching. Interesting immediates (ports, magic numbers, crypto key sizes) are extracted per function. The new `--html` flag produces a dark-theme, filterable report with an inline SVG entropy bar chart — no external dependencies, works offline.

---

## What's included

### Section entropy

Every section in the binary is scored with Shannon entropy and assigned a verdict:

| Entropy | Verdict |
|---------|---------|
| < 1.0 | packed |
| ≤ 6.5 | normal |
| ≤ 7.2 | compressed |
| > 7.2 | encrypted |

Known packer section name signatures (`UPX0/1/2`, `MPRESS1/2`, `.packed`, `.themida`) are detected and reported as a `Packer` field in binary info.

Sections appear in both JSON output and the new HTML report's entropy bar chart.

### Embedded asset detection (`--assets`)

When `--assets` is enabled, GoRipper finds path-like strings (has file extension, not absolute, no shell-special characters) referenced by functions that call into `embed.*` or `io/fs.*`. The detected paths are reported as `embedded_assets` in JSON and in the text/HTML report.

### Constant extraction

For x86_64 functions, GoRipper scans each instruction for interesting immediates and classifies them:

| Category | Examples |
|----------|---------|
| `port` | 21, 22, 80, 443, 4444, 31337, … |
| `magic` | `0x5A4D` (PE), `0x7F454C46` (ELF), `0x504B0304` (ZIP), … |
| `crypto_key_size` | 16, 24, 32, 48, 64 — only inside CRYPTO-tagged functions |

Constants appear as `constants` on each `FunctionOutput` in JSON. ARM64 is skipped — immediates are not reliably distinguishable from normal arithmetic without full semantic analysis.

### HTML report (`--html`)

`--html` writes a self-contained dark-theme HTML report to stdout (use `-o report.html` to save):

```bash
goripper analyze ./malware.exe --html -o report.html
```

Features:
- Inline SVG entropy bar chart — bars color-coded by verdict
- Summary cards for key metrics
- Filterable tables for functions, strings, embedded assets, and types
- No external dependencies — works fully offline
- Mutually exclusive with `--json` and `--jsonl`

### Memory guard (`--max-memory-mb`)

`--max-memory-mb N` skips the CFG stage when the binary exceeds N MB, emitting a warning instead of running out of memory on very large binaries. Default `0` = no limit (backward compatible).

### Chunked rodata scan

The `.rodata` string scanner now processes data in 4 MB chunks with a 512-byte overlap, keeping peak allocation bounded on large binaries without changing extraction results.

## New flags

| Flag | Command | Description |
|------|---------|-------------|
| `--html` | `analyze` | Emit self-contained HTML report (mutually exclusive with `--json`/`--jsonl`) |
| `--assets` | `analyze` | Detect embedded asset paths via embed/io/fs callgraph |
| `--max-memory-mb N` | `analyze` | Skip CFG stage when binary exceeds N MB |
