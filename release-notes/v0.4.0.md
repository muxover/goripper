# GoRipper v0.4.0 — Taint analysis, YARA generation, threat classification, IDA/Ghidra export

**Release date:** 2026-05-17

### Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.4.0
```

Or download a prebuilt binary from the [releases page](https://github.com/muxover/goripper/releases/tag/v0.4.0).

---

## Summary

Output is now directly actionable. Taint analysis traces untrusted input to dangerous sinks through the call graph. YARA rules are generated automatically from high-signal strings. A rule-based threat classifier gives a verdict without reading the full report. IDA and Ghidra scripts flow recovered function names and behavior tags into the RE tools analysts already use.

## What's included

### Taint analysis (`--taint`)

Inter-procedural source-to-sink reachability through the call graph. Taint propagates upward through CalledBy edges — callers of tainted functions may receive tainted return values.

**Sources:** `os.Args`, `os.Stdin`, `os.Getenv`, `os.LookupEnv`, `os.ReadFile`, `os.Open`, `net/http.Request.Body`, `net.Conn.Read`, `bufio.Scanner`

**Sinks:** `os/exec.Command`, `syscall.Exec`, `database/sql.Query`, `database/sql.Exec`, `os.WriteFile`, `os.Create`, `net.Conn.Write`, `http.ResponseWriter.Write`, `encoding/json.Unmarshal`, `encoding/gob.Decode`, `html/template.Execute`

```json
{
  "source":      "os.Args",
  "source_func": "main.parseArgs",
  "sink":        "os/exec.Command",
  "sink_func":   "main.runCommand",
  "path":        ["main.parseArgs", "main.buildCmd", "main.runCommand"],
  "confidence":  "high"
}
```

Confidence: `high` (≤2 hops) · `medium` (3–4 hops) · `low` (5–8 hops). On binaries with >5000 user functions, warns and suggests `--only-user`.

### YARA rule generation (`goripper yara`)

New subcommand. Selects up to 30 high-signal strings and emits a valid YARA rule with PE or ELF format condition.

Selection priority:
1. URL and secret strings — unique, high confidence
2. Path strings (non-stdlib)
3. For obfuscated binaries (garble score > 0.5): pclntab function names

```bash
goripper yara ./malware.exe -o rules.yar
```

```yara
rule malware {
    meta:
        description = "Auto-generated by GoRipper v0.4.0"
        obfuscation = "0.12"
        date        = "2026-05-17"
    strings:
        $s0 = "https://discord.com/api/webhooks/123456/abcdef"
        $s1 = "api_key"
    condition:
        uint16(0) == 0x5A4D and 2 of ($s*)
}
```

### Threat classification

Runs on every analysis — no flag needed. Rule-based, no external API, no ML.

| Class | Key signals |
|-------|-------------|
| `RAT` | NETWORK + EXECUTION + FILE_READ/WRITE + concurrency |
| `DOWNLOADER` | NETWORK + FILE_WRITE + URL strings, no EXECUTION |
| `RANSOMWARE` | CRYPTO + FILE_WRITE + file extension enumeration strings |
| `C2_AGENT` | NETWORK + DNS + CRYPTO + concurrency |
| `KEYLOGGER` | FILE_WRITE + keylog API strings |
| `CRYPTOMINER` | NETWORK + mining pool URL strings |
| `TOOL` | no NETWORK, EXECUTION, or MEMORY tags |
| `UNKNOWN` | insufficient signal |

Result in `summary.threat_class`, `summary.threat_confidence`, `summary.threat_indicators`.

### IDA Pro export (`--ida`)

Emits an IDAPython script that renames all pclntab functions to their Go names, applies behavior tags as repeatable comments, and bookmarks concurrent functions. Standalone `.py` — no IDA plugin required.

```bash
goripper analyze ./malware.exe --ida -o rename.py
```

### Ghidra export (`--ghidra`)

Emits a GhidraScript (Java) that renames functions at their addresses, applies pre-comments with behavior tags, and annotates recovered struct types. Run via Ghidra's Script Manager.

```bash
goripper analyze ./malware.exe --ghidra -o rename.java
```

### Flags

| Flag | Description |
|------|-------------|
| `--taint` | Run inter-procedural taint analysis (on `analyze`) |
| `--ida` | Emit an IDAPython rename script (on `analyze`) |
| `--ghidra` | Emit a GhidraScript (Java) rename script (on `analyze`) |
| `goripper yara <binary>` | New subcommand — generate a YARA rule |

`--ida` and `--ghidra` are mutually exclusive with `--json`, `--jsonl`, `--html`, and each other.
