# GoRipper v0.1.0 — First Stable Release

**Released:** 2026-03-29

## Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.1.0
```

Or download a prebuilt binary from the [releases page](https://github.com/muxover/goripper/releases/tag/v0.1.0).

---

## Summary

First stable release. Promotes the project from nine pre-release iterations to a
production-ready tool with verified PE and ELF support, a complete analysis pipeline,
cross-platform release binaries, and full documentation.

No new pipeline features — this release is the graduation of everything shipped in
`v0.0.1-pre` through `v0.0.9-pre`. The focus was correctness, documentation, and
release infrastructure.

---

## What's new

### `callgraph --depth N` now works

The flag was registered and accepted since v0.0.1-pre but had no effect. It now caps
the callee list per node at N entries and appends a trailing count line:

```
main.main
  ├── net/http.Get
  ├── fmt.Println
  └── ... and 14 more
```

Default `0` = unlimited (backward compatible).

### `docs/architecture.md`

New contributor documentation covering:
- Full pipeline flowchart (`binary bytes → loader → gopclntab → functions → ... → output`)
- Per-package table: package path, what it owns, key types
- Data flow from `Binary` interface to `AnalysisResult`
- String extraction internals (3-pass: header pairs, LEA cross-reference, post-processing)
- How to add a new pipeline stage
- How to add a new behavior tag
- Known limitations

### Cross-platform release binaries

GitHub Actions release pipeline builds and publishes prebuilt binaries on every `v*` tag:

| Binary | Platform |
|--------|----------|
| `goripper-linux-amd64` | Linux x86_64 |
| `goripper-linux-arm64` | Linux ARM64 |
| `goripper-darwin-amd64` | macOS Intel |
| `goripper-darwin-arm64` | macOS Apple Silicon |
| `goripper-windows-amd64.exe` | Windows x86_64 |

Each release includes `checksums.txt` (SHA-256).

## Fixes

- `callgraph --depth` was a no-op since v0.0.1-pre — now limits callee count per node.
- Dead code removed from `internal/types/recovery.go`: unused `patterns` loop that
  iterated over a slice and discarded every element.
- Duplicate `Run` doc comment removed from `pkg/analyzer/analyzer.go`.
