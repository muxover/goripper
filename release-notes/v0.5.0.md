# GoRipper v0.5.0 — Multi-binary analysis: similarity, clustering, module graph

**Release date:** 2026-05-21

### Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.5.0
```

Or download a prebuilt binary from the [releases page](https://github.com/muxover/goripper/releases/tag/v0.5.0).

---

## Summary

GoRipper can now analyze binaries as a family, not in isolation. Similarity hashing makes function-level comparison fast and architecture-neutral. `scan-dir` scales that to a whole directory in parallel. The module graph tells you exactly what third-party code is in the binary and whether any version carries a known CVE.

## What's included

### Function similarity hashing

Every user function gets a 16-character hex `similarity_hash` in `FunctionOutput`. The hash is computed from the normalized instruction sequence — opcodes and indirect flags only; all immediates, addresses, and branch targets are stripped. Two functions that differ only in constants or call targets produce the same hash.

```json
{
  "name": "main.runCommand",
  "addr": "0x401000",
  "similarity_hash": "3a7f9c2e1b4d8e0f"
}
```

### `goripper compare` — cross-binary shared code

```bash
goripper compare a.exe b.exe [--json]
```

```
=== GoRipper Compare ===
  binary A: a.exe
  binary B: b.exe

Shared functions:  312
Unique to A:       45
Unique to B:       28
Similarity score:  0.87

Shared packages (3):
  main
  github.com/user/c2lib
  github.com/user/loader
```

`SimilarityScore = shared / max(totalA, totalB)`. Score > 0.7 indicates a shared codebase.

### `goripper scan-dir` — batch parallel analysis

```bash
goripper scan-dir ./samples/ [--workers N] [--only-go] [--cluster] [--json | --jsonl]
```

Recursively walks the directory, identifies Go binaries, and analyzes each in parallel. Output is JSONL by default (one object per binary). `--only-go` filters by gopclntab magic before analyzing.

| Flag | Description |
|------|-------------|
| `--workers N` | Parallel workers (default: CPU count) |
| `--only-go` | Skip files without gopclntab magic |
| `--cluster` | Group results by code similarity after scanning |
| `--json` | JSON array instead of JSONL |

### Malware family clustering

```bash
goripper scan-dir ./samples/ --cluster
```

```
Cluster 1 (4 samples, similarity 0.91):
  sample_a.exe
  sample_b.exe
  sample_c.exe
  sample_d.exe
  Shared packages: main, github.com/user/loader, github.com/user/c2

Cluster 2 (2 samples, similarity 0.73):
  dropper_v1.exe
  dropper_v2.exe
  Shared packages: main, github.com/user/dropper
```

Single-linkage clustering. Threshold: 0.6 similarity. Binaries below the threshold are not grouped.

### Module dependency graph (`--modules`)

```bash
goripper analyze ./malware.exe --modules [--json]
```

Reads `debug/buildinfo` to recover the full Go module dependency tree. Reports path, version, and used-function count per dependency. Cross-references against a bundled CVE table.

```json
{
  "module_graph": {
    "main_module": "github.com/attacker/rat",
    "go_version":  "go1.22.1",
    "dependencies": [
      {
        "path":           "github.com/gorilla/websocket",
        "version":        "v1.4.1",
        "used_functions": 12,
        "cves":           ["CVE-2020-27813"]
      },
      {
        "path":           "golang.org/x/crypto",
        "version":        "v0.17.0",
        "used_functions": 45
      }
    ]
  }
}
```

Bundled CVE table covers 7 high-impact Go library vulnerabilities (gorilla/websocket, x/crypto, gin, jwt-go, gogo/protobuf, x/net, miekg/dns). Module graph also appears as a `"type":"module_graph"` record in JSONL output.

### Flags

| Flag | Command | Description |
|------|---------|-------------|
| `--modules` | `analyze` | Recover module dependency graph from build info |
| `--workers N` | `scan-dir` | Parallel analysis workers (default: CPU count) |
| `--only-go` | `scan-dir` | Skip non-Go binaries |
| `--cluster` | `scan-dir` | Group results by code similarity |
| `goripper compare <a> <b>` | — | New subcommand |
| `goripper scan-dir <dir>` | — | New subcommand |
