# GoRipper v0.0.9-pre

**Released:** 2026-03-26

## Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.0.9-pre
```

## Summary

Pipeline-friendly release. `--jsonl` streams output line-by-line for jq/grep workflows.
`--max-functions` tames large binaries. `--quiet` strips decorative noise for scripting.
Shell completion ships for free via cobra.

## What's Included

| Feature | Description |
|---------|-------------|
| `--jsonl` | Stream analysis as JSONL — one typed object per line. Pipe to `jq`, `grep`, or any ndjson tool. Mutually exclusive with `--json`. |
| `--max-functions N` | Cap function list output at N entries with a trailing count line. On `analyze` and `functions`. |
| `-q` / `--quiet` | Suppress all `===` headers and section labels. Emit data rows only. Inherited by every subcommand. |
| `goripper completion` | Shell completion for bash, zsh, fish, and powershell via cobra. `--type` on `strings` completes known values. |
| README overhaul | All commands, flags, and defaults now accurate. Limitations, shell completion, and quick-start examples updated. |

## Pipeline Examples

```bash
# Extract all URL strings from a binary
goripper analyze malware.exe --jsonl | jq 'select(.type=="string" and .string_type=="url") | .value'

# See only new behavior tags in a diff
goripper diff v1.exe v2.exe --json | jq '.new_behaviors'

# Quiet function list for grep
goripper functions malware.exe --only-user --quiet | grep "main\."
```
