# GoRipper v0.0.9-pre — JSONL streaming, max-functions, quiet flag, shell completion

**Release date:** 2026-03-26

### Install

```bash
go install github.com/muxover/goripper/cmd/goripper@v0.0.9-pre
```

---

## Summary

Pipeline-friendly release. `--jsonl` streams output line-by-line for jq/grep workflows.
`--max-functions` tames large binaries. `--quiet` strips decorative noise for scripting.
Shell completion ships for free via cobra. Also fixes the `goripper diff` usability issue
where cross-version comparisons dumped thousands of runtime function diffs.

---

## What's included

### `--jsonl` streaming output

Emits one JSON object per line with a `"type"` discriminator. Order:
`binary_info` → `function` → `string` → `behavior` → `summary` (always last).

```bash
# Extract all URL strings
goripper analyze malware.exe --jsonl | jq 'select(.type=="string" and .string_type=="url") | .value'

# See only behavior tags
goripper analyze malware.exe --jsonl | grep '"type":"behavior"'
```

Mutually exclusive with `--json`. Available on `analyze`.

### `--max-functions N`

Caps the function list at N entries and appends a trailing count line:

```
... and 14,831 more functions (use --max-functions 0 for full list)
```

Default `0` = unlimited (backward compatible). Available on `analyze` and `functions`.

### `-q / --quiet`

Persistent flag on the root command — inherited by every subcommand. Suppresses all
`===` section headers, grouping lines, binary info block, and summary block. Errors
still go to stderr.

```bash
# Grep-friendly function list
goripper functions malware.exe --only-user --quiet | grep "main\."
```

### Shell completion

`goripper completion <shell>` generates shell completion scripts for bash, zsh, fish,
and powershell via cobra's built-in machinery. The `--type` flag on `strings` completes
`url`, `ip`, `path`, `secret`, `pkgpath`.

```bash
goripper completion bash >> ~/.bashrc
goripper completion zsh  >> ~/.zshrc
goripper completion fish > ~/.config/fish/completions/goripper.fish
goripper completion powershell >> $PROFILE
```

### `goripper diff` filter flags

`--no-runtime` and `--only-user` added to `diff`. Without these, comparing binaries
built with different Go toolchain versions would produce thousands of spurious runtime
function diffs, burying the real signal.

## Tests

3 new tests in `internal/output`.

| Test | Description |
|------|-------------|
| `TestWriteJSONL_EachLineIsValidJSON` | Every line in JSONL output parses as valid JSON |
| `TestWriteJSONL_SummaryIsLast` | Last line always has `"type":"summary"` |
| `TestWriteJSONL_TypesPresent` | All five type discriminators appear in output |
| `TestWriteJSONL_BinaryInfoFirst` | First line always has `"type":"binary_info"` |
| `TestTextWriter_MaxFunctions_Truncates` | Truncation message appears when over limit |
| `TestTextWriter_MaxFunctions_NoTruncateWhenUnderLimit` | No truncation message when under limit |
| `TestTextWriter_Quiet_NoHeaders` | All `===` headers suppressed in quiet mode |
